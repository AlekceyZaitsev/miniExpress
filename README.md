# MiniExpress — Lightweight HTTP Router Engine

**MiniExpress** — это легковесный бэкенд-фреймворк на Node.js, написанный с нуля для глубокого понимания HTTP абстракций. В отличие от готовых решений, этот проект реализует механизмы маршрутизации и безопасности на уровне ядра без внешних зависимостей.

## 🎯 Зачем я это создал?
Большинство разработчиков используют Express без понимания его внутренней работы. **MiniExpress** создан, чтобы показать:
- Как устроен роутинг под капотом (Map + RegExp).
- Как предотвращать уязвимости типа **Regex Injection**.
- Практика чистого функционального программирования в экосистеме JS/TS.

## ✨ Ключевые возможности
- ⚡ **Zero Dependencies**: Только стандартные модули Node.js (`http`, `url`) + TypeScript.
- 🛠️ **Динамическая маршрутизация**: Поддержка путей вида `/users/:id`. Автоматическое извлечение параметров в `req.params`.
- 🔒 **Security First**: Встроенное экранирование спецсимволов для защиты от Regex Injection уязвимостей.
- 🧱 **Type-Safe Architecture**: Строгая типизация методов и роутов через TypeScript интерфейсы.
- 🔄 **Functional Core**: Реализован через Factory Functions (без классов), что обеспечивает простоту тестирования и модульность.

## 🏗 Архитектура

  const id = req.params.userId;
